# AegisAuth — Swift Example

Swift client for macOS/iOS using modern `async/await`, `URLSession`, and `CryptoKit`.

---

## 🚀 Running the Example

```bash
swift main.swift
```

---

## ⚙️ Configuration

Open `main.swift` and update the constants:

```swift
let authUrl = "https://auth.example.com"
let appKey = "YOUR_APP_KEY"
let appName = "My Application"
let appVersion = "1.0.0"

let username = "YOUR_USERNAME"
let password = "YOUR_PASSWORD"
let moduleName = "minecraft"
```
