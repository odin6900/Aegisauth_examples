# AegisAuth — JavaScript Example

Node.js client for **AegisAuth** using ES modules (`.mjs`) with zero third-party dependencies (Node.js 18+ native `fetch` and `crypto`).

---

## 🚀 Running the Example

```bash
node index.mjs
```

---

## ⚙️ Configuration

Open `index.mjs` and update your constants:

```javascript
const AUTH_URL = "https://auth.example.com";
const APP_KEY = "YOUR_APP_KEY";
const APP_NAME = "My Application";
const APP_VERSION = "1.0.0";

const USERNAME = "YOUR_USERNAME";
const PASSWORD = "YOUR_PASSWORD";
const MODULE_NAME = "minecraft";
```
